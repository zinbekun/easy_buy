# easy_buy（買い出しリスト）

イオンネットスーパーの商品を自動で集めて一覧表示し、選んだ商品を Google スプレッドシートの買い出しシートへまとめて転記するローカル Web アプリです。

対象店舗はイオンスタイル津田沼Ｎｏｒｔｈ（店舗コード `01050000006660`）に固定しています。

## できること

- **商品一覧**: お菓子・カップ麺・飲み物は税込み128円未満、日用品（ティッシュ・ウェットティッシュ・紙コップ・割りばし）は値段の上限なしで、イオンネットスーパーと同じカード形式で表示
- **探す・並べる**: 商品名での横断検索、価格・五十音・内容量での並び替え、前回購入した商品の絞り込み
- **選ぶ**: チェックで選択。選択はブラウザに保存され、ジャンル別の個数を上部に表示
- **転記**: 選んだ商品を、名称・分類・購入リンク・価格・数量・小計の形でシートに書き込む
- **協力モード**: 今回選んだジャンルの行だけを置き換え、ほかのジャンルの行はシートに書かれたまま残す
- **楽チン**: 前回の転記内容を、値段が同じで販売中の商品だけ引き継いで選択。入れ替えが必要な数をジャンルごとに表示し、個数も前回から引き継ぐ
- **購入履歴**: 直近5回の転記を、商品ごとの購入回数つきで表示
- 取得中は、転がる柴犬のプログレスバーを表示

## 必要なもの

- Python 3.12（Linux / WSL で動作確認）
- Google Sheets API を有効にした Google Cloud プロジェクトと、サービスアカウントの JSON キー

## セットアップ

```bash
git clone git@github.com:zinbekun/easy_buy.git
cd easy_buy
./run.sh
```

`run.sh` は初回に `venv/` を作り、依存パッケージを入れてから起動します。ブラウザで http://127.0.0.1:8765/ が開き、その日の商品情報がまだなければ自動で取得します（約3分）。終了は Ctrl+C です。

### スプレッドシート連携（初回のみ）

1. Google Cloud Console でプロジェクトを作り、Google Sheets API を有効にする
2. サービスアカウントを作成し、JSON キーをダウンロードする
3. キーを `credentials/service_account.json` として保存する
4. 転記先のスプレッドシートを、キー内の `client_email` に**編集者**として共有する
5. アプリの「選択商品」画面でスプレッドシートの URL を入力し、「シートを読み込む」を押して転記先のタブを選ぶ

`credentials/` と `data/` は `.gitignore` の対象です。認証鍵や履歴をコミットしないでください。

### テンプレート（任意）

完全に空のタブへ転記したとき、指定したテンプレートのタブを丸ごとコピーしてから書き込めます（プルダウン・色・フォント・列幅も同じになります）。使う場合は `credentials/template.json` を置きます。

```json
{"spreadsheet_id": "テンプレートのスプレッドシートID", "sheet_id": 123456789}
```

`sheet_id` はタブの URL の `gid=` の値です。テンプレートもサービスアカウントに共有してください。設定がない場合、空のタブへの転記はエラーになります。

## シートの形式

| セル・列 | 内容 |
| --- | --- |
| B2 | 申請日（転記した日を自動入力） |
| E2 / F2 | 「総計」の見出し / 総計（数式がなければ `=sum(G開始行:G)` を入れる） |
| B列 | 名称 |
| C列 | 分類（お菓子・カップ麺・飲み物・日用品） |
| D列 | 購入リンク（「おうちでイオン　イオンネットスーパー　商品名」にリンクを付ける） |
| E列 | 価格（税込み） |
| F列 | 数量 |
| G列 | 小計（`=E*F`） |
| H列 | コメント |

- B列に「名称」、E列に「価格」を含む行を見出し行とみなし、その下から最終行までを商品データの領域にします
- 通常は商品データの領域を全部置き換えます。数式のセルは維持します
- 協力モードでは、今回出力しないジャンルの行を、リンク・数量・コメントも含めて残します。行はジャンルの順に並べ直します
- 転記の順番はお菓子 → カップ麺 → 飲み物 → 日用品で、ジャンル内は安い順（同じ価格なら五十音順）です

## 商品情報の取得

ブラウザから 1 ページずつサーバーに取得を依頼し、1.5 秒の間隔を空けて売場の一覧ページを巡回します。サイトの `robots.txt` が禁止している `/netsuper/*/*/` の形の URL（売場の小分類ページや検索ページ）は使いません。

| ジャンル | 読む売場 | 絞り込み |
| --- | --- | --- |
| お菓子 | `1M.html` | 税込み128円未満 |
| カップ麺 | `1G.html`（麺類全体） | 税込み128円未満。商品名で明らかにカップ麺でないもの（袋麺の一部・つゆ・パスタなど）を除外 |
| 飲み物 | `1R.html` | 税込み128円未満 |
| 日用品 | `8A.html`（紙・生理用品・介護）、`8F.html`（キッチン用品） | 値段の上限なし。商品名でティッシュ・ウェットティッシュ・紙コップ・割りばしに分類 |

- 128円の判定がある売場は税抜価格の安い順に読み、税抜128円に達した時点で打ち切ります
- 一覧に出ている価格（セール中はセール後の価格）を採用します。カゴボタンがない商品や売り切れ表示の商品は除外します
- 内容量は商品名から読み取ります
- 1 か所でも取得に失敗した場合は（各ページ最大3回再試行）、一覧を更新せず前回の内容を残します

### 分類の限界

カップ麺と日用品は売場の小分類ページを使えないため、商品名で判定しています。カップ麺には袋麺などが、日用品には名前に語を含む別の商品が混ざることがあります。

`config.py` の `USE_CUP_NOODLE_SUBCATEGORY = True` にすると、カップ麺を小分類ページから正確に取得します。ただしこの URL は `robots.txt` の禁止範囲に当たります。

## データの保存先

| ファイル | 内容 |
| --- | --- |
| `data/products.json` | 取得した商品情報（1日1回更新） |
| `data/history.json` | 直近5回の転記履歴 |
| `data/settings.json` | 転記先のスプレッドシート URL とタブ |

選択中の商品と協力モードのオン／オフは、ブラウザの localStorage に保存します。

## 開発

```bash
venv/bin/pip install -r requirements-dev.txt
venv/bin/python -m pytest
```

ROS などで `PYTHONPATH` が設定されている環境では、`env -u PYTHONPATH venv/bin/python -m pytest` で実行してください。

サーバーはコードの変更を検知すると自動で読み込み直します。

| ファイル | 役割 |
| --- | --- |
| `app.py` | Flask サーバーと API |
| `scraper.py` | 一覧ページの取得と解析、ジャンルの判定 |
| `sheets.py` | スプレッドシートへの転記（協力モード・テンプレートのコピーを含む） |
| `history.py` | 購入履歴と楽チン機能の引き継ぎ内容 |
| `storage.py` | 保存先（`data/` のファイル。環境変数があれば Upstash Redis） |
| `static/` | 画面（HTML / CSS / JavaScript、柴犬のアニメーション） |
| `tests/` | テスト |

## 注意

- 個人の買い出しを楽にするためのツールです。サイトへの負荷を抑えるため、自動取得は1日1回、ページの取得は1.5秒間隔にしています
- データセンター（クラウド）からのアクセスはサイト側で拒否されるため、手元の PC で動かしてください
